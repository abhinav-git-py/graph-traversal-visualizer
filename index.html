Quick GitHub Pages Instructions:
  1. Create a new repository on github.com named graph-visualizer
  2. In this project directory, run: 
    git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/graph-visualizer.git
git push -u origin main
  3. Go to your GitHub repo → Settings → Pages → Select Branch main and root / → Click Save!
  4. Your visualizer will immediately be live at https://YOUR_USERNAME.github.io/graph-visualizer/
